1. Резюме спецификации

Scope: agent/pipeline.py — снять один guard. Без правок prompt-файлов и embeddings.json.

Требования

IDСекцияТребование
R1ProblemOracle-атомы знаний не доходят до PLAN при ECOM_INVESTIGATE_ENABLED=1 (default) — блок «VALIDATED KNOWLEDGE — APPLY» отсутствует в PLAN.
R2Problemembeddings.json — не причина (red herring): синхронен с atoms.yaml, одна строка из-за json.dumps без indent.
R3Root causeoracle_atoms заполняется только в ветке if not _investigate_on → при INVESTIGATE on остаётся [].
R4Root causebuild_oracle_block([]) → "" → блок знаний не попадает в PLAN-промпт.
R5Root causeАтомы из investigate идут только в router (_atoms_block), не сохраняются в Brief, не доходят до PLAN.
R6Approach AСнять guard if not _investigate_on — oracle.retrieve(instruction) в обоих режимах кормит oracle_atoms в PLAN.
R7Why safeПозиция до INTENT сохранена; retrieve уважает ECOM_ORACLE_ENABLED=0 и embed-сбой; _oracle не расходуется.
R8Cost+1 retrieve/задачу при INVESTIGATE on (query embed + cosine + опц. 1 fast-LLM rerank, гасится ECOM_ORACLE_RANK_ENABLED=0).
R9Rejected BАккумуляция step-scoped атомов в Brief отклонена — меняет семантику, UNPROVEN, лишний плюмбинг.
R10Out of scopeembeddings.json, data/prompts/*, орфан-векторы vec-cache не трогаются.
