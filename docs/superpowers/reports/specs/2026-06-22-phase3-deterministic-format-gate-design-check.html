1 · Резюме спецификации

Гарантировать, что answer.message детерминированно соответствует точному контракту формата. Модель предлагает контент — код формирует поверхность.

Требования по секциям

СекцияТребование
GoalДетерминированное соответствие answer.message контракту формата: EUR %d.%02d, <YES>/<NO>, count: %d, yes/no-токены из /AGENTS.MD.
Design.1
Typed formatters		При типизированном intent.answer_shape рендерить значение нужным форматтером: money→format_eur, boolean→токены из /AGENTS.MD, count→точная %d-строка задачи, table/quote→точный TSV. Перезаписывает сообщение модели.
Design.2
Gate guards		Зеркало exoskeleton answer_formatter: сохранять не-OK сообщения; short-circuit при точном совпадении; normalise-only — откат к оригиналу при пустом/неудачном форматировании, срез лишнего префикса OUTCOME_*.
Design.3
AGENTS.MD tokens		Читать кастомные yes/no-токены из per-trial /AGENTS.MD (уже загружен оркестратором).
Componentsagent/format_gate.py (новый: format_answer + format_eur, bool_tokens, already_exact); agent/pipeline.py (вызов перед vm.answer); agent/interpreter.py (проброс сырого типизированного значения).
Error handlingBest-effort, никогда не бросает; неудача форматирования возвращает оригинал; не-OK не переформатируется.
TestingUnit (format_eur округление/локаль, bool-токены, short-circuit, preserve не-OK); Integration (replay t04/t06/t07/t08 + EUR-regex → message матчит regex); Regression (полный набор зелёный, не менять уже прошедшие сообщения).

Success Criteria

  • Устранён format-class feedback (verify fail / Answer should contain) на затронутых задачах.
  • Нет регрессии на задачах, где сообщение уже совпадало.

Non-goals

  • Производство refs (Phase 1), решения по outcome (Phase 2).
  • Нет LLM-переформатирования в дефолтном пути — опциональный fast-tier reshape для free-text это будущее расширение.

2 · Схемы решения и зависимостей

Схема решения — поток перед vm.answer

interpretвычисленное значение + raw value
→
Phase 1refs произведены
→
Phase 2outcome decision
→
format_gate.format_answer(message, intent, answer_shape, agents_md)
→
vm.answerединственный вызов
Ветвление внутри format_answer:
  • если outcome != OK → passthrough (preserve не-OK)
  • если already_exact(message) → passthrough (short-circuit)
  • иначе по answer_shape: money→format_eur | boolean→bool_tokens(agents_md) | count→%d string | table/quote→TSV
  • при ошибке/пустом результате → fallback к оригиналу
